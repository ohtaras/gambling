# Κυνηγός Κλειδιών — GPU + CPU (υβριδικό)

Αναζήτηση Bitcoin Puzzle #71 που τρέχει **ταυτόχρονα** στη GPU (WebGPU, secp256k1 σε WGSL)
και στον επεξεργαστή (ο βελτιστοποιημένος CPU κινητήρας, Web Workers). Οι δύο μηχανές
μοιράζονται το εύρος σε chunks (65.536) χωρίς επικάλυψη και η ταχύτητα αθροίζεται.

- 100% τοπικά/offline (CSP connect-src none· οι workers είναι τοπικοί blob). Το κλειδί, αν βρεθεί, μένει στη συσκευή.
- Αυτο-έλεγχος ορθότητας του secp256k1 κατά την εκκίνηση.
- Συμβατό με τη μορφή προόδου `KYN1:` (Εισαγωγή/Εξαγωγή με αντιγραφή/επικόλληση), μονάδα chunk 65.536.
- Chrome/Edge (Windows/Mac/Android) και Safari iOS 26+.
